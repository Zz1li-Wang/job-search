[源码摘要](source-manifest.json)列出本轮最终源码、配置、迁移和测试的SHA256，便于复核交付内容。测试以归档JSON的实际数量、时间和退出码为准；检查区间不是全部开发工时。

生产容器演练使用单独命名的Compose项目、临时凭据及合成标记；验证HTTPS、全部迁移就绪、公网内部/MCP拒绝、真实验证码、API重启和Worker共享文件卷、备份与数据库/文件恢复，完成后删除该项目及其卷。本机原pgsql-local服务不属于清理对象。TLS采用本地localhost证书，此项不等于公网证书或上线验证。

## 实际限制与未执行项

- 当前业务库不填充虚构岗位或画像。真实5条取样及缺口仍在[采集交付](../ingestion/README.md)，完整人工条件核验0；历史取样不代表当前全站实时覆盖。
- 持续来源网络默认关闭。真实模型历史5次、来源累计53次，本轮没有新增预算，也没有偷偷消耗剩余或重置预算。新Agent适配器的本轮端到端验证使用受控模型HTTP，新增DeepSeek实测仍待预算。
- 工作台非岗位列表有首版数量上限，见运行契约；扫描PDF不OCR，无邮箱/手机密码找回，不自动投递。
- CI文件已准备，本地检查已执行；没有远端仓库运行记录、服务器部署、公网URL或7天在线结果。需要明确远端/域名/平台及授权后再执行这些操作。
- 对话导出由工作区同步脚本维护；本轮最终回复只能在下一轮开始补齐，不存在后台实时监听。
