## 原因与修复

- 日期原始格式与内部精度规范不一致，自定义校验没有完整进入模型JSON Schema。已补可序列化格式约束和原文明示精度说明，保留日历校验，不补未知月日。
- 日期证据定位到对象而非/value时可作无歧义转换，明确字段引用优先；学历状态与毕业性质必须有明确原文，不能按时间推断。
- 经历自由文本说明采用已经定位并逐字核验的引用，避免把模型改写当作经历；不存在或错误引用仍拒绝。
- Agent的结构错误原本变成500通用错误，Worker又全部映射成MODEL_INTERRUPTED。现在内部接口只透传白名单内既有错误码，客户端验证信封，页面区分格式无效与中断；未知错误仍保守处理，不自动计费重试。
