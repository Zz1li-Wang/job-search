## 已复现并修复的问题

1. 源站sourceId是不透明字符串，虽然形似UUID，但不符合标准UUID版本/variant的情况很多。已存公开样本28个ID中25个会被严格z.uuid()拒绝。
2. 旧Cookie验证器错误地使用严格UUID；正文摘要校验抛错又被捕获成network_error，抹掉已收到HTTP的事实。
3. 已改为保留源站标识原始结构、不限制UUID版本。仅网络发送失败才记HTTP0；收到响应后的正文/元数据处理错误保留HTTP状态并单独标记。
4. 加入真实源站非标准ID和超限正文的回归用例。测试通过只能证明修复后的本地行为，不能替代Cookie实际复测。
