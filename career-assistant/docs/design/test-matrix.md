# 接口和模块测试矩阵

版本 0.1；待用户确认。**所有用例均为待实现、待执行，不是测试通过报告。**具体测试随相应模块本地提交，未获方案确认前不编写业务代码或测试代码。

## 测试层和公共断言

每个下表操作 ID 对应独立的测试分组，不允许仅测试路由存在。需要对照实际路由注册、MCP tools/list 和 CLI 注册表检查遗漏。

- BASE-P：成功输出契约、缺失/非法输入、错误映射、无敏感信息、限流适用情况。
- BASE-U：BASE-P + 未认证401、失效会话、跨用户私有资源404、写入的 Origin/CSRF 拒绝和失败无业务副作用。
- BASE-S：BASE-P + 服务凭据、运行范围、过期授权、User撤销状态、模型参数不能伪造身份。
- BASE-O：参数校验、受保护本地执行、错误退出、输出契约、无凭据泄漏。
- 写入另测事务回滚；K 操作测重复同内容、同键异内容、并发相同键，结果和副作用各验证一次。
- DTO 测类型、长度、必填、默认和关联校验；领域测状态与不变量；Service 测编排及异常；Repository 用真实 PostgreSQL 测映射、唯一约束、CAS、锁、回滚及并发连接。
- 验证失败需要断言数据没有错误变化，不能只断言 HTTP 状态码。

## 模块 E2E 与完成标准

| E2E ID | 真实入口和依赖 | 成功链路 | 必含失败/边界 |
| --- | --- | --- | --- |
| E2E-VERIFY | 获批验证入口、可控适配器、报告文件 | 来源/模型/文档到能力报告 | 配置缺失、失败标识；真实外部调用单列 |
| E2E-FOUNDATION | 实际服务进程、真实PostgreSQL | 迁移、就绪、写入、重启读取、回滚 | 错配置、断库、事务失败、架构越界检查 |
| E2E-AUTH | 浏览器、API、数据库 | 注册、登录、me、改密码、重登 | 验证码重放、用户名竞争、旧会话撤销 |
| E2E-INGEST | CLI、Worker、来源替身、DB、快照 | 发现、入库、草稿、核验、更新、导出 | 重试、checkpoint、迟到租约、原文变化失效 |
| E2E-JOBS | 浏览器、API、岗位证据DB | 搜索、详情、来源、刷新状态 | 无结果、下架、来源冲突、匿名拒绝 |
| E2E-ELIG | API/MCP、真实DB、领域规则 | 画像/岗位版本到逐项结果 | 社招应届、未知条件、截止、依赖竞争 |
| E2E-AGENT | 独立Agent服务、MCP、模型替身 | 工具循环、建议、结构化结果和事件回调 | 超时、预算、注入、身份、取消失败 |
| E2E-MCP | 真实MCP传输及Service/DB | 握手、tools/list、逐工具调用 | 输入错误、isError映射、授权、重复写工具 |
| E2E-CHAT | 浏览器、API、Agent、MCP、DB | 多轮、引用卡片、SSE回放 | 重复消息、忙、断线、乱序事件、假设不改画像 |
| E2E-RESUME | 浏览器、Worker、Agent、MCP、文件/DB | 上传、提取、草稿及私有读取 | 格式伪装、扫描、模型失败、跨用户、删除竞争 |
| E2E-PROFILE | 浏览器、API/DB | 编辑草稿、用户确认、使用正式画像 | 版本冲突、重复确认、未知字段及来源定位 |
| E2E-FAVORITE | 浏览器、API/DB | 添加、查看、取消、重登 | 重复、跨用户、过期岗位 |
| E2E-APPLICATION | 浏览器、API/DB | 建记录、状态日期备注、历史和删除 | CAS冲突、重复创建、未来日期、历史写失败 |
| E2E-PRIVACY | 浏览器、API、Worker、文件/DB | 资料/账号删除及物理清理 | 文件失败、迟到任务、会话撤销、公共岗位保留 |
| E2E-WORKSPACE | 全部已验收模块 | 注册到画像、咨询、核验、管理、删除 | 移动端、键盘、空状态、错误和重连 |

模块完成必须同时满足接口测试、领域/Service/Repository测试、适用的并发测试、本地启动及本模块 E2E。用户验收另行记录。不能以一个全站 E2E 替代上表各模块。

## 测试数据和执行记录规范

- 虚构学生：本科预计毕业、已毕业硕士、专业未知、无正式经验但有实习、生日边界、重叠工作经历、证书未知；均标测试数据。
- 虚构岗位夹具：社招经验不限、经验要求三年、AND/OR混合、缺截止、当天无时刻、明确关闭、公告冲突、文档变化；不进入生产岗位库冒充采集结果。
- 时间通过时钟注入，测试跨日、时区、48小时边界和生日，不依赖机器当前时间。
- 并发通过两个真实连接及同步屏障启动，在最终 DB 状态和受影响行数上断言；不以 Promise.all 本身证明真正发生竞争。
- 数据库测试使用隔离测试库，不对生产库执行清理。各 E2E 有独立用户、来源命名空间和幂等标识，结束清理。
- CI常规运行可控替身，不消耗真实模型或高频访问来源。真实外部 smoke 验证在授权配置下单列调用时间、模型、来源、成功范围和限制。
- 测试报告记录命令、提交/文档版本、环境、通过/失败/未运行及原因。本文只定义将来的用例，没有任何代码测试执行结论。
