## 本轮建议重点检查

- 完整条件首版由运营对照原文核验，其他大量采集记录保留待核验。这会限制肯定性推荐数量，但不伪报覆盖；后续若自动核验需单独提出可验证方案。
- 日期只写到天、当天未明确时刻时不作肯定性推荐；长期招聘也不永久认定开放。
- 首版会话串行；模型结果未知不自动重试；用户主动重试可能再次计费。
- 画像只能经草稿确认写入；删除简历和清空画像是不同操作。
- 账号与采集模块均已验收；本轮确认第七步只读画像依赖、条件树兼容语义、最近收录排序及三态判断。后续模块本轮按批量授权完成，运行契约和局限集中提交检查。

确认记录需记录原用户指示、日期、模块和版本，不自行补填“已确认”。实质变更提升版本并重新确认。
