# 第七步：岗位查询与资格阶段记录

按用户“将后面任务全部写完吧，明天我来检查”的批量授权实现，完成后继续后续模块，尚未记录为用户验收。

已实现岗位列表/筛选/签名分页、详情和证据、只读正式画像、三态核验创建/历史读取及对应页面，共6个新增HTTP操作。规则包含学历取得状态、预计毕业、同一教育记录约束、专业精确匹配、年龄/闰日、合并工作区间、证书未知、组合和例外；未核验、过期或资料不足保持待核验，社招不直接排除应届。

构建、Lint、类型、架构边界和19个HTTP清单检查通过。49个单元、60个真实PG/HTTP/CLI集成及9个浏览器/进程E2E通过，包含新E2E-JOBS和E2E-ELIG。机器报告见[单元](unit-tests.json)、[集成](integration-tests.json)、[E2E](e2e-tests.json)。原验证工具77项本阶段未重跑，最终统一回归时单列，不冒充本轮结果。

当前根业务库未填充虚构岗位或画像，真实来源取样仍为独立导出；无正式画像时返回null/version0及待核验。测试用虚构已确认画像验证应届匹配社招的正向路径。没有真实模型/来源请求、推送或部署。
